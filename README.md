Computer Monitoring System

# Описание проекта

**Computer Monitoring System — это система мониторинга состояния компьютеров, состоящая из Python-агентов и центрального сервера.
На каждом компьютере запускается специальный **Python Agent**, который периодически собирает информацию о состоянии системы и отправляет её на сервер.
Сервер принимает телеметрию от агентов, сохраняет историю показателей, определяет текущее состояние компьютеров, обнаруживает превышение заданных порогов и формирует уведомления о проблемах.

# Python Agent

На каждом отслеживаемом компьютере запускается Python-агент. Агент периодически собирает информацию о состоянии компьютера:

* загрузка процессора;
* использование оперативной памяти;
* использование дискового пространства;
* температура процессора;
* имя компьютера;
* IP-адрес;
* время последней активности.

Пример собранных данных:

```text
CPU:         34%
RAM:         62%
Disk:        71%
Temperature: 54°C
```

# Основной функционал

Система предоставляет следующий функционал:

* сбор информации о состоянии компьютеров;
* мониторинг CPU;
* мониторинг RAM;
* мониторинг дискового пространства;
* мониторинг температуры;
* отправка telemetry на сервер;
* heartbeat-механизм;
* определение состояния компьютера;
* обнаружение offline-компьютеров;
* хранение истории показателей;
* получение статистики;
* агрегация time-series данных;
* настройка пороговых значений;
* обнаружение превышения порогов;
* создание alert-событий;
* отслеживание восстановления системы;
* защита от повторяющихся уведомлений;
* асинхронная обработка событий через RabbitMQ;
* кэширование текущего состояния через Redis;
* отправка уведомлений;
* REST API;
* автоматическая документация API;
* контейнеризация с Docker.
